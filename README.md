# Zorvian

An AI-powered cross-border financial platform concept for Africa.

## Status
Early-stage prototype. The current web app uses fictional balances and simulated activity only. It does not move real money, hold assets, connect to banks, or provide financial services.

## Product direction
- Multi-currency wallet experience
- Cross-border transfer and exchange journeys
- Conversational AI assistant
- Digital-asset interface concepts
- Web, mobile, and messaging experiences

## Safety principles
- All prototype balances and transactions are fictional.
- No payment or asset movement occurs.
- A future AI-assisted transaction must require explicit user confirmation before execution.
- Real-money services require licensed providers, compliance controls, security reviews, and legal approval.

## Technology direction
- React + TypeScript + Vite (web)
- React Native + Expo (planned mobile app)
- Node.js + TypeScript (planned backend)
- PostgreSQL (planned persistence)

## Run
```bash
npm install
npm run dev
```

First milestone: establish the Zorvian visual identity, responsive web shell, and navigation.
